# Chunky Monkeys

This directory contains the currently accepted Chunky Monkeys NFT assets.

- Images: `images/{token_id}.png`
- Metadata: `metadata/{token_id}.json`
- Published range: `1` through `3000`
- Image format: square 512×512 PNG
- Legendary Chicken Poop editions in this release: 44, 444, 777, 1234, 1666,
  2026, 2222, 2444, 2555, 2666

Metadata image URLs target the repository's `main` branch and become live after
the publishing pull request is merged.
